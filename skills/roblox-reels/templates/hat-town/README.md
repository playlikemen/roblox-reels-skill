# Hat Town (worked example)

The full source of the 42 s short "In this town, every lie makes your hat one block taller".

| Path | What it is |
|---|---|
| `story/script.txt` | Narration, one sentence per line |
| `story/voice/words.json` | Word times (regenerated by `build.sh`) |
| `src/hat/story.ts` | Shot plan, camera keys, per-frame direction, stickers. Everything is anchored to word times with `W(line, word)` |
| `src/hat/world.ts` | The town square, buildings, cast, the tower |
| `src/hat/chars.ts` | Blocky 6-part characters, drawn faces, block hats |
| `src/hat/kit.ts` | Toon materials, ink hulls, signs, sticker sprites |
| `src/hat/HatTown.tsx` | The Remotion composition |
| `stills.mjs` | Stills from one bundle: `node stills.mjs out/stills/a_ 20,100,300 0.5` |

```bash
npm install
bash ../../scripts/build.sh        # voice -> word times -> sound -> frames -> encode -> captions -> QA
```
