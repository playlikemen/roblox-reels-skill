Story reels made in code, not in a video generator.

Claude writes the "In this town" script, voices it, plans every shot against the spoken words, renders a blocky 3D town with three.js in Remotion, mixes the sound and burns in Shorts-safe captions. Everything runs on your own machine. No GPU needed.

Install

Pick one. Each way also updates: run it again, or use the update commands.

Claude Code plugin Recommended

Run inside Claude Code.

/plugin marketplace add playlikemen/roblox-reels-skill /plugin install roblox-reels@roblox-reels

Update later:

/plugin marketplace update roblox-reels /plugin update roblox-reels@roblox-reels

One-line installer

Copies every skill to ~/.claude/skills. Run again to update.

curl -fsSL https://raw.githubusercontent.com/playlikemen/roblox-reels-skill/main/install.sh | bash

Only some skills, or into this project:

curl -fsSL https://raw.githubusercontent.com/playlikemen/roblox-reels-skill/main/install.sh | bash -s -- roblox-reels captions
curl -fsSL https://raw.githubusercontent.com/playlikemen/roblox-reels-skill/main/install.sh | SKILLS_DIR=.claude/skills bash

How a reel is made

Ask: "Use the roblox reels skill and make an 'In this town' reel about a town where it rains whatever people are thinking."

ScriptRule in line one, "except me", planted details, a twist, a comment hook.
VoiceLocal Kokoro voice, word times from faster-whisper.
Shot planEvery cut, sticker and face change lands on a spoken word.
RenderToon-shaded blocky town in three.js, stills checked before the full render.
Sound + captionsDucked music, synthesized effects, -14 LUFS, 2-3 word captions.
QAEvery frame checked for black, frozen and popping frames.
